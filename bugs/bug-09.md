# BUG-09: POST /api/books буруу JSON биетэй хүсэлтэд 400 биш 200 OK {"result":"OK"} буцаадаг ч юу ч хадгалдаггүй

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.85, Windows 11 Home (10.0.26200), 2026-10-20  
**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном); өөр терминалд curl ашиглана

## Дахин гаргах алхам

1. Аппыг шинээр асаана.
2. curl -i -X POST localhost:3000/api/books -d 'буруу оролт'
3. curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title": "X", '
4. curl -i localhost:3000/api/books

**Хүлээгдэж байсан:** «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»

**Бодит үр дүн:** Хоёр хүсэлт хоёулаа «HTTP/1.1 200 OK» ба {"result":"OK"} буцаана. Гэтэл дараагийн GET /api/books-д шинэ ном НЭМЭГДЭЭГҮЙ (шинэ апп дээр 3 ном хэвээр). Өөрөөр хэлбэл API алдааг илрүүлэхгүй төдийгүй «амжилттай» гэж худал хариулна.

**Ноцтой байдал:** Critical — API хэрэглэгч (өөр программ) хүсэлт амжилттай болсон гэж үзэх ч өгөгдөл чимээгүй алга болно; алдааг илрүүлэх, дахин оролдох боломжгүй.
