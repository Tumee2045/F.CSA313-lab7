# BUG-12: «Нэмэх» товчны сүүлийн үсэг кирилл «х» биш латин «x» (U+0078) — нүдэнд ижил ч текст буруу

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.85, Windows 11 Home (10.0.26200), 2026-10-20  
**Урьдчилсан нөхцөл:** node app.js-ийг шинээр асаасан (анхны 3 ном); өөр терминалд curl ашиглана

## Дахин гаргах алхам

1. Аппыг шинээр асаана.
2. curl -s localhost:3000 | grep 'Нэмэ'  — товчны HTML-ийг харна.
3. Гаралтад «Нэмэ» гэсний дараах үсгийн Unicode кодыг шалгана (evidence/bug-12-chars.txt-д тэмдэгт бүрийн кодыг гаргасан).

**Хүлээгдэж байсан:** «... текстүүд үсгийн алдаагүй.» — товч бүхэлдээ кирилл «Нэмэх» (Н-э-м-э-х, сүүлийнх нь U+0445) байх ёстой.

**Бодит үр дүн:** Товчны текст «Нэмэx»: Н U+041D, э U+044D, м U+043C, э U+044D, x U+0078 (латин). Нүдээр ялгагдахгүй ч хайлт, дэлгэц уншигч (screen reader), автомат тест кириллээр «Нэмэх» товчийг олохгүй.

**Ноцтой байдал:** Cosmetic — харагдах байдал зөв, функц ажилладаг; гэхдээ хүртээмж (accessibility) ба автоматжуулалтад саад болно.
